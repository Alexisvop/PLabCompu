\subsubsection{Fundamento: modelo de Phong con varias fuentes}
Con una sola fuente, el modelo de Phong suma una componente ambiental, una difusa y una especular, escaladas por la potencia de la luz y atenuadas con el cuadrado de la distancia \cite{hearn_baker}. Con varias fuentes, la luz es aditiva: el color de cada fragmento es la suma de las contribuciones de todas las fuentes \cite{learnopengl}. Para $N$ fuentes,
\begin{equation}
    L_o = \sum_{i=1}^{N} \left[ k_{a,i} + k_{d,i}\,\max(0, \mathbf{n} \cdot \mathbf{l}_i) + k_{s,i}\,\max(0, \mathbf{v} \cdot \mathbf{r}_i)^{q_i} \right] \frac{P_i}{d_i^2}
    \label{eq:phong_multi}
\end{equation}
donde $k_{a,i} = M_a \odot C_i$, $k_{d,i} = M_d \odot C_i$ y $k_{s,i} = M_s \odot C_i$ son los productos, canal por canal, del color del material por el color $C_i$ de la fuente; $\mathbf{l}_i$ es la dirección del fragmento hacia la fuente $i$, $\mathbf{r}_i$ su reflejo respecto a la normal $\mathbf{n}$, $\mathbf{v}$ la dirección hacia el observador, $q_i$ el exponente especular, $P_i$ la potencia y $d_i$ la distancia. La normal y la dirección al observador son las mismas para todas las fuentes; lo que cambia de una a otra es $\mathbf{l}_i$ y, con ella, $\mathbf{r}_i$.

Dos consecuencias de la Ecuación \ref{eq:phong_multi} guiaron el diseño. La primera es que el término ambiental no depende de la geometría, así que crece con cada fuente que se agrega y se suma igual en toda la escena: con diez fuentes, la suma ambiental es diez veces mayor que con una. La segunda es que el resultado se recorta a 1 en cada canal al escribirse en el \textit{framebuffer}, por lo que hay que repartir la energía entre las fuentes para no saturar la imagen.

\subsubsection{Implementación en el \textit{shader}}
El \textit{fragment shader} \texttt{11\_PhongShaderMultLights.fs} ya implementa la Ecuación \ref{eq:phong_multi}. Declara un arreglo de estructuras \texttt{Light} con tamaño \texttt{MAX\_LIGHTS}, que vale 10, y un entero \texttt{numLights} con cuántas fuentes están en uso. En \texttt{main()} recorre las primeras \texttt{numLights} fuentes, calcula en espacio de cámara la dirección hacia cada una y acumula en \texttt{ex\_color} lo que devuelve \texttt{ApplyLight}, que evalúa las tres componentes de Phong para una fuente (Listado \ref{lst:shader_multi}). Al final multiplica el resultado por el texel de la textura difusa. Como el arreglo tiene exactamente 10 posiciones, diez es el máximo de fuentes que admite el \textit{shader} sin modificarlo; no fue necesario cambiar el \textit{shader}.

\begin{lstlisting}[language=C++, caption={Acumulación de las fuentes en 11\_PhongShaderMultLights.fs.}, label={lst:shader_multi}]
#define MAX_LIGHTS 10
uniform int numLights;

uniform struct Light {
   vec3  Position;
   vec3  Direction;
   vec4  Color;
   vec4  Power;
   int   alphaIndex;
   float distance;
} allLights[MAX_LIGHTS];

// ...

for(int i = 0; i < numLights; ++i){
    vec3 EyeDirection_cameraspace = vec3(0,0,0) - vertexPosition_cameraspace;
    vec3 LightPosition_cameraspace = ( view * vec4(allLights[i].Position,1)).xyz;
    vec3 LightDirection_cameraspace = LightPosition_cameraspace + EyeDirection_cameraspace;
    vec3 e = normalize(EyeDirection_cameraspace);
    vec3 l = normalize( LightDirection_cameraspace );
    ex_color += ApplyLight(allLights[i], n, l, e);
}
\end{lstlisting}

Igual que en la práctica 7, $d_i$ no es la distancia real a la fuente sino el \textit{uniform} \texttt{distance} de cada luz, fijo en 3. Por lo tanto, el factor $P_i/d_i^2$ es constante y las fuentes no se debilitan con la distancia: lo que cambia de un punto a otro son los cosenos de la componente difusa y de la especular.

\subsubsection{Envío de las fuentes al \textit{shader}}
En cada cuadro, \texttt{Update()} pasa las fuentes al \textit{shader} como \textit{uniforms} con las funciones auxiliares \texttt{SetLightUniform*} del código base, que arman nombres como \texttt{allLights[3].Color}. El código original enviaba todas las fuentes del vector y ponía \texttt{numLights} igual a su tamaño. Lo modificamos para poder apagar fuentes: solo se envían las que están encendidas, compactadas al inicio del arreglo con un contador \texttt{activeLights}, y \texttt{numLights} recibe ese contador (Listado \ref{lst:uniforms}). Compactar es necesario porque el \textit{shader} recorre las posiciones $0$ a $\texttt{numLights}-1$: si solo se saltara una fuente apagada sin compactar, quedaría un hueco con los datos del cuadro anterior. Los marcadores de las fuentes apagadas tampoco se dibujan.

\begin{lstlisting}[language=C++, firstnumber=287, caption={Envío de las fuentes encendidas en Update() (08\_IllumModels2.cpp).}, label={lst:uniforms}]
// Configuramos propiedades de fuentes de luz
// Solo se envían las luces encendidas, compactadas al inicio del arreglo
size_t activeLights = 0;
for (size_t i = 0; i < gLights.size(); ++i) {
	if (!gLightEnabled[i])
		continue;
	SetLightUniformVec3(mLightsShader, "Position", activeLights, gLights[i].Position);
	SetLightUniformVec3(mLightsShader, "Direction", activeLights, gLights[i].Direction);
	SetLightUniformVec4(mLightsShader, "Color", activeLights, gLights[i].Color);
	SetLightUniformVec4(mLightsShader, "Power", activeLights, gLights[i].Power);
	SetLightUniformInt(mLightsShader, "alphaIndex", activeLights, gLights[i].alphaIndex);
	SetLightUniformFloat(mLightsShader, "distance", activeLights, gLights[i].distance);
	++activeLights;
}
mLightsShader->setInt("numLights", (int)activeLights);
\end{lstlisting}

\subsubsection{Controles}
Para encender y apagar cada fuente usamos las teclas numéricas: de la 1 a la 9 para las fuentes 1 a 9, y el 0 para la fuente 10. Como \texttt{processInput} se ejecuta en cada cuadro, si solo se revisara que la tecla está presionada la fuente cambiaría de estado decenas de veces mientras se mantiene apretada. Por eso guardamos el estado anterior de cada tecla en \texttt{gLightKeyPressed} y solo cambiamos la fuente en el cuadro en que la tecla pasa de suelta a presionada, es decir, en el flanco de subida (Listado \ref{lst:teclas}). La Tabla \ref{tab:controles} resume los controles.

\begin{lstlisting}[language=C++, firstnumber=369, caption={Encendido y apagado de las fuentes en processInput() (08\_IllumModels2.cpp).}, label={lst:teclas}]
// Encender/apagar luces: teclas 1-9 para las luces 1-9 y 0 para la luz 10
for (int i = 0; i < NUM_LIGHTS; ++i) {
	int key = (i == 9) ? GLFW_KEY_0 : GLFW_KEY_1 + i;
	bool pressed = glfwGetKey(window, key) == GLFW_PRESS;
	if (pressed && !gLightKeyPressed[i])
		gLightEnabled[i] = !gLightEnabled[i];
	gLightKeyPressed[i] = pressed;
}
\end{lstlisting}
