\begin{abstract}
En esta práctica de laboratorio se implementó el proceso de adaptación y carga de modelos tridimensionales complejos mediante el lenguaje C++ y la biblioteca gráfica OpenGL 3.3 en perfil núcleo, utilizando la biblioteca Assimp para la importación e interpretación de formatos externos (como FBX u OBJ). A lo largo de la práctica se estructuró una clase para el procesamiento de mallas (Mesh) y modelos (Model), gestionando la transferencia de geometría, coordenadas de textura y normales hacia búferes de vértices (VBO) y arreglos de vértices (VAO). Los resultados obtenidos permitieron la integración exitosa de objetos 3D detallados dentro de la escena interactiva, optimizando el rendimiento mediante la gestión eficiente de memoria en la GPU y la organización jerárquica de mallas.

\vspace{0.3cm}
\noindent\textbf{Palabras clave:} Carga de modelos, Assimp, mallas 3D, OpenGL, FBX, shaders, VAO/VBO.
\end{abstract}

\renewcommand{\abstractname}{Abstract}
\begin{abstract}
In this laboratory session, the process of adapting and loading complex three-dimensional models was implemented using C++ and OpenGL 3.3 core profile, leveraging the Assimp library for importing and parsing external file formats (such as FBX or OBJ). Throughout the practice, a dedicated class architecture was designed to handle meshes and models, managing the transfer of geometry, texture coordinates, and normals to vertex buffer objects (VBO) and vertex array objects (VAO). The obtained results allowed the successful integration of detailed 3D assets into an interactive scene, optimizing performance through efficient GPU memory management and hierarchical mesh organization.

\vspace{0.3cm}
\noindent\textbf{Keywords:} Model loading, Assimp, 3D meshes, OpenGL, FBX, shaders, VAO/VBO.
\end{abstract}
