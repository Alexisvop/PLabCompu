\subsection{Actividad 1: Creacion de una casa sencilla con OpenGL}
Para construir la casa decidimos extender el mismo patrón que ya usábamos con la clase \texttt{Triangle3D}, en vez de armar una jerarquía nueva de clases. La idea fue simple: una casa vista desde estas prácticas no es más que un cubo (las paredes) con una pirámide de base cuadrada encima (el techo), así que creamos una clase \texttt{House3D} que arma exactamente esa geometría.

El constructor recibe dos parámetros, \texttt{size} (la mitad del ancho del cubo) y \texttt{roofHeight} (qué tan alto sobresale el techo respecto a la parte superior del cubo), y dejamos también un constructor de conveniencia que solo pide \texttt{size} y usa esa misma medida como altura del techo. Definimos 9 vértices en total: los primeros 8 corresponden a las esquinas del cubo (4 abajo y 4 arriba) y el noveno es el vértice donde convergen las cuatro caras del techo. Para que la figura quedara centrada en el origen, todas las coordenadas se calculan como desplazamientos de \texttt{size} respecto a $(0,0,0)$, de modo que sin importar qué tan grande o pequeña se haga la casa, su centro geométrico siempre cae en el origen.

Reutilizamos los vértices superiores del cubo como base del techo en vez de duplicarlos, lo que ahorra memoria pero implica que el color se interpola entre la pared y el ápice del techo. Aprovechamos esto a nuestro favor: le dimos a las paredes un tono claro y al vértice del ápice un tono rojizo, de modo que el degradado que genera OpenGL al interpolar los colores termina pareciendo un techo de color distinto, sin necesidad de duplicar geometría ni complicar el shader.

Los índices se organizaron por caras: dos triángulos para el piso, dos por cada una de las cuatro paredes, y cuatro más para las caras del techo (cada una toma una arista del cuadrado superior y la une con el ápice). Decidimos no dibujar la cara superior del cubo porque queda completamente tapada por el techo, evitando así geometría innecesaria.

\begin{lstlisting}[language=C, caption=Código de la construccion de la casa (House3D), label=lst:codigo-casa]
    void buildVertices(float size, float roofHeight) {

	// Color de las paredes (tono claro tipo estuco)
	float wr = 0.85f, wg = 0.80f, wb = 0.65f;

	Vertex v;

	// Paredes, 8 vertices
	// Cara inferior (y = -size)
	v.Position = vec3(-size, -size, -size); setColor(v, wr, wg, wb); vertices.push_back(v); // 0: fondo-izq-abajo
	v.Position = vec3(size, -size, -size); setColor(v, wr, wg, wb); vertices.push_back(v); // 1: fondo-der-abajo
	v.Position = vec3(size, -size, size); setColor(v, wr, wg, wb); vertices.push_back(v); // 2: frente-der-abajo
	v.Position = vec3(-size, -size, size); setColor(v, wr, wg, wb); vertices.push_back(v); // 3: frente-izq-abajo

	// Cara superior (y = size)
	v.Position = vec3(-size, size, -size); setColor(v, wr, wg, wb); vertices.push_back(v); // 4: fondo-izq-arriba
	v.Position = vec3(size, size, -size); setColor(v, wr, wg, wb); vertices.push_back(v); // 5: fondo-der-arriba
	v.Position = vec3(size, size, size); setColor(v, wr, wg, wb); vertices.push_back(v); // 6: frente-der-arriba
	v.Position = vec3(-size, size, size); setColor(v, wr, wg, wb); vertices.push_back(v); // 7: frente-izq-arriba

	// Techo, vertice 8
	v.Position = vec3(0.0f, size + roofHeight, 0.0f);
	setColor(v, 0.55f, 0.20f, 0.12f);
	vertices.push_back(v); // 8
    }

    void buildIndices() {

	// Piso (cara inferior del cubo) 
	indices.push_back(0); indices.push_back(1); indices.push_back(2);
	indices.push_back(0); indices.push_back(2); indices.push_back(3);

	// Pared trasera (z = -size) 
	indices.push_back(0); indices.push_back(1); indices.push_back(5);
	indices.push_back(0); indices.push_back(5); indices.push_back(4);

	// Pared frontal (z = size) 
	indices.push_back(3); indices.push_back(2); indices.push_back(6);
	indices.push_back(3); indices.push_back(6); indices.push_back(7);

	// Pared izquierda (x = -size) 
	indices.push_back(0); indices.push_back(3); indices.push_back(7);
	indices.push_back(0); indices.push_back(7); indices.push_back(4);

	// Pared derecha (x = size) 
	indices.push_back(1); indices.push_back(2); indices.push_back(6);
	indices.push_back(1); indices.push_back(6); indices.push_back(5);

	// Techo: piramide de base cuadrada (4,5,6,7) con apex en 8 
	indices.push_back(4); indices.push_back(5); indices.push_back(8); // cara trasera
	indices.push_back(5); indices.push_back(6); indices.push_back(8); // cara derecha
	indices.push_back(6); indices.push_back(7); indices.push_back(8); // cara frontal
	indices.push_back(7); indices.push_back(4); indices.push_back(8); // cara izquierda
}

\subsection{Actividad 2: Configuración de las vistas: frontal, lateral y superior}
Para las tres vistas no fue necesario tocar la lógica de renderizado ni las matrices de proyección: bastó con manipular los tres vectores que recibe \texttt{glm::lookAt}, que ya estaban expuestos en el objeto \texttt{camera} (\texttt{Position}, \texttt{View} y \texttt{Up}). El código original ya tenía las teclas F1, F2 y F3 conectadas a bloques que modificaban esos vectores, pero al revisarlo notamos que las posiciones no correspondían a lo que pedía la práctica (una de las vistas quedaba en diagonal en vez de frontal, y las otras dos estaban intercambiadas entre lado y superior), así que rehicimos los tres bloques desde cero.

Colocamos la cámara sobre cada uno de los ejes principales, siempre apuntando hacia el origen, que es donde vive la casa: F1 sobre el eje $+Z$ para la vista frontal, F2 sobre el eje $+X$ para la vista lateral, y F3 sobre el eje $+Y$ para la vista superior. El único ajuste que requirió pensarlo dos veces fue el vector \texttt{Up} de la vista superior: como ahí la cámara mira directamente hacia abajo a lo largo del eje $Y$, no podíamos dejar \texttt{Up} apuntando también en $Y$, porque quedaría paralelo a la dirección de vista y \texttt{lookAt} no tendría forma de saber hacia dónde orientar la parte superior de la imagen. Resolvimos esto usando $(0,0,-1)$ como \texttt{Up} solo para esa vista, dejando $(0,1,0)$ para las otras dos.

\begin{lstlisting}[language=C, caption=Código de las vistas: frontal, lateral y superior, label=lst:codigo-vistas]

if (glfwGetKey(window, GLFW_KEY_F1) == GLFW_PRESS) {
    // Vista frontal: camara sobre el eje +Z mirando hacia el origen
    camera.Position = glm::vec3(0.0f, 0.0f, 3.0f);
    camera.View = glm::vec3(0.0f, 0.0f, 0.0f);
    camera.Up = glm::vec3(0.0f, 1.0f, 0.0f); //rotacion
}
if (glfwGetKey(window, GLFW_KEY_F2) == GLFW_PRESS) {
    // Vista de lado: camara sobre el eje +X mirando hacia el origen
    camera.Position = glm::vec3(3.0f, 1.0f, 1.0f); // Lo modifique para que se viera el lado, ya que si lo pongo literal de lado, no habria diferencia entre el frontal y el lado debido a que son pares las caras 
    camera.View = glm::vec3(0.0f, 0.0f, 0.0f);
    camera.Up = glm::vec3(0.0f, 1.0f, 0.0f);
}
if (glfwGetKey(window, GLFW_KEY_F3) == GLFW_PRESS) {
    // Vista superior: camara sobre el eje +Y mirando hacia abajo
    camera.Position = glm::vec3(0.0f, 3.0f, 0.0f);
    camera.View = glm::vec3(0.0f, 0.0f, 0.0f);
    camera.Up = glm::vec3(0.0f, 0.0f, -1.0f);
}
\end{lstlisting}
